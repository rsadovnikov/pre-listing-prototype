# Отчёт до публикации — прототип

[Открыть прототип](https://rsadovnikov.github.io/pre-listing-prototype/?view=map)

React-прототип: поиск и карта, подборки, создание отчёта по цене и конкурентам.

Этот репозиторий содержит только статическую сборку. Исходники и общий UI-kit ведутся отдельно. Данные пользователя сохраняются в localStorage его браузера; серверной базы нет. PDF демонстрационный и статический.

Обновление: локальная команда npm run deploy:pages в проекте прототипа. GitHub Pages публикует main из корня репозитория.
